# Mobile-Phone-Sales-PBI
# 📱 Mobile Phone Sales Dashboard

An interactive **Mobile Phone Sales Dashboard** built using **Microsoft Power BI** to analyze mobile phone sales, brands, models, ratings, memory configurations, discounts, and customer preferences.

The dashboard provides a comprehensive view of mobile phone sales performance through interactive KPIs, charts, slicers, and visual analytics.

---

## 📊 Dashboard Preview

![Mobile Phone Sales Dashboard](./PBI%20IMG.png)

---

## 🎯 Project Overview

The **Mobile Phone Sales Dashboard** is designed to transform mobile phone sales data into meaningful business insights.

It enables users to analyze:

- Total number of records
- Number of mobile brands
- Total sales
- Maximum and minimum sales
- Sales by memory capacity
- Sales performance by brand
- Mobile ratings
- Discounts by brand
- Models by memory configuration
- Brand-wise sales performance

## 📈 Dashboard Features

### 🏷️ Count of Models by Brands

A bar chart showing the number of mobile models available across different brands.

Top brands include:

- Samsung
- Apple
- realme
- OPPO
- Nokia
- Xiaomi
- Infinix
- GIONEE

This visualization helps identify brands with the largest number of models in the dataset.

---

### 💾 Sales by Memory

A donut chart displays the distribution of sales across different memory configurations, including:

- 2 GB
- 3 GB
- 4 GB
- 6 GB
- 8 GB
- 12 GB
- Other configurations

This helps understand customer demand for different memory capacities.

---

### 💰 Average Sales by Brands

A comparative visualization showing average sales performance across different mobile brands.

This can help identify brands with stronger average sales values.

---

### 📦 Count of Models by Memory

A treemap displays the number of mobile models associated with different memory configurations.

This makes it easy to compare the availability of models across memory categories.

---

### 🏷️ Discount Analysis

The **Sum of Discount by Brands** chart provides a brand-wise comparison of discounts offered.

It helps analyze discount distribution and identify brands contributing the most to total discounts.

---

### ⭐ Rating Analysis

The **Sum of Rating by Brands** visualization compares ratings across different brands and provides an overview of brand-level rating performance.

---

## 🎛️ Interactive Filters

The dashboard includes multiple slicers that allow users to dynamically filter the analysis.

### Available Filters

- **Models**
- **Rating**
- **Memory**
- **Colors**
- **Storage**
- **Brands**

Users can select individual or multiple values to explore specific segments of the mobile phone dataset.
